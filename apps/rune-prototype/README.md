# Caelum Rune prototype

An interactive, fixture-based workspace for comparing Rune with Caelum's polished Tauri UI.

From the repository root:

```sh
nix develop -c cargo run --locked --manifest-path apps/rune-prototype/Cargo.toml
```

See the [comparison guide](../../docs/design/README.md) for screenshots, interactions, keyboard shortcuts, capture commands and checks. Replies are simulated and state is kept in memory for the current run.
